# Task 1: Exploratory Data Analysis (EDA) on Retail Sales Data

## Domain
Data Analytics — Oasis Infobyte SIP

## Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on an online retail transactions dataset. The objective is to identify sales patterns, peak purchasing periods, top-performing product categories, and geographic revenue distributions to provide actionable business recommendations.

## Tech Stack & Libraries
* **Language**: Python 3
* **Libraries**: Pandas, NumPy, Matplotlib, Seaborn

## Key Findings & Visualizations
* **Seasonality & Trends**: Monthly sales trends reveal noticeable transaction spikes in Q4, driven by wholesale pre-holiday ordering.
* **Geographical Distribution**: The United Kingdom generates the majority of revenue, with substantial international volume originating from Germany and France.
* **Revenue Drivers**: Order quantity is the primary driver of invoice value, reflecting wholesale purchasing behaviors.
* **Recommendations**: Implemented safety stock buffering for Q4, geographic promotion expansion in top European markets, and high-demand product bundling.

## Folder Contents
* `task1_eda.ipynb`: Full Jupyter notebook containing data cleaning, exploratory analysis, charts, and markdown commentary.
* `retail_sales_dataset.csv`: Dataset used for the analysis.
